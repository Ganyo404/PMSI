# Daftar Skill AI Agent (PMSI Perpustakaan FT UNY)

Berikut adalah keahlian (*skills*) yang dapat digunakan oleh AI Agent dalam project ini, baik yang bawaan repositori maupun *Native Antigravity Skills* di folder `.agents/skills/`:

---

### 1. Academic Skill
*(Native Antigravity Skill di `.agents/skills/academic-skill/SKILL.md`)*
Digunakan untuk penulisan laporan akademik.
Ketentuan:
- Bahasa Indonesia akademik natural, merujuk pada 7 Aspek MSI Bu Ratna.
- Tidak kaku; anti-AI Writing (tanpa kata *slop* dan tanpa tanda *em-dash*).
- Mempertahankan solusi *Pure Governance* (tanpa memaksakan koding software baru).
- Menegakkan *Vertical Alignment 3 Tingkat Organisasi* (Dekanat, Pustakawan Tunggal, Pemustaka).

---

### 2. Source Tracking / Revisi Skill
*(Native Antigravity Skill di `.agents/skills/revisi/SKILL.md`)*
Digunakan untuk:
- Melacak sumber dan tidak membabat habis paragraf lama saat revisi (*Substance First*).
- Menjaga garis keturunan artefak (*lineage*) antar-modul.
- Membuat histori revisi di folder `07_REVISI/`.

---

### 3. Self Audit Skill (QA/QC & Constructive Dialectic)
*(Native Antigravity Skill di `.agents/skills/self-audit/SKILL.md`)*
Digunakan untuk:
- Memeriksa laporan dan mewajibkan standar Diagram `mermaid`.
- Protokol Dialektika Konstruktif: Menelaah deviasi tata kelola secara kritis, mencegah angka fiktif, dan merekomendasikan solusi harmonisasi bersama pengguna tanpa resistensi kaku.
- Memeriksa kelengkapan 7 Bagian wajib Laporan Praktikum dan rubrik nilai A Bu Ratna.

---

### 4. Modul Generator Skill
*(Native Antigravity Skill di `.agents/skills/buat-modul/SKILL.md`)*
Digunakan untuk:
- Memandu tata cara pembuatan Laporan Modul baru secara konsisten.
- Mewajibkan *Implementation Plan* sebelum menulis kode/naskah utuh.

---

### 5. Obsidian Graph Skill
*(Native Antigravity Skill di `.agents/skills/obsidian-graph/SKILL.md`)*
Digunakan untuk:
- Manajemen graf pengetahuan Obsidian dan resolusi simpul terisolasi (*orphan nodes*).
- Menjaga Dashboard sebagai *Mother Hub / Central Nexus* (Jantung Utama Graf).

---

### 6. Self-Healing Skill
*(Native Antigravity Skill di `.agents/skills/self-healing/SKILL.md`)*
Digunakan untuk pemulihan dan perbaikan mandiri:
- Deteksi dan perbaikan otomatis tautan rusak (*broken wikilinks*) ke file target riil.
- Perbaikan otomatis sintaks diagram Mermaid yang gagal render.
- Rekonsiliasi diskontinuitas deliverable (mengembalikan deliverable yang hilang di modul lanjutan).
- Koreksi akuntabilitas RACI (1 Accountable tunggal) dan eliminasi em-dash / AI slop words.

---

### 7. Problem Solving & Systemic Reasoning Skill
*(Native Antigravity Skill di `.agents/skills/problem-solving/SKILL.md`)*
Digunakan untuk:

- Menganalisis keputusan dengan *Trade-Off Matrix* (membuktikan keunggulan tata kelola dibanding koding aplikasi baru).
- Memastikan kategorisasi kendala dan solusi bersifat *MECE (Mutually Exclusive, Collectively Exhaustive)*.

---

### 8. Fact-Checker & Evidence Verification Skill

### 20. Hyperframes Video & Animation Engine Skills
*(Native Antigravity Skills di `.agents/skills/hyperframes*` dan `.agents/skills/media-use/`)*
Digunakan untuk pembuatan aset presentasi visual, motion graphics, video terprogram, dan video demo:
- **`hyperframes`**: Fondasi framework pembuatan video terprogram dan rendering animasi.
- **`hyperframes-animation`**: Desain motion graphics, kurva easing, dan orkestrasi transisi visual.
- **`hyperframes-creative`**: Arahan kreatif, storyboard, estetika tipografi video, dan komposisi frame.
- **`hyperframes-keyframes`**: Kontrol penentuan waktu (timings), properti keyframe, dan interpolasi gerak.
- **`hyperframes-core`**: Core runtime, arsitektur data frame, dan pipeline rendering utama.
- **`hyperframes-studio`**: Manajemen environment studio dan workspace visual preview.
- **`hyperframes-cli`**: Eksekusi perintah command-line untuk render, build, dan inspect aset Hyperframes.
- **`media-use`**: Integrasi dan utilisasi aset multimedia (video klip, audio, gambar, dan elemen grafis).
- **`hyperframes-audio`**: Sinkronisasi audio latar, voiceover, sound effect, dan waveform ke timeline.

### 21. Uizze Modern UI/UX & Anti-Slop Skills
*(Native Antigravity Skills di `.agents/skills/ui-*` dan `.agents/skills/anti-ui-slop/`)*
Digunakan untuk perancangan antarmuka premium, anti-slop, dan audit standar desain:
- **`ui-design`**: Perancangan antarmuka aplikasi modern, token desain, state management visual (loading, error, empty).
- **`anti-ui-slop`**: Eliminasi layout generik, penguatan hierarki informasi, dan penanganan kontrol inert / status mentah.
- **`ui-radar`**: Investigasi keputusan UI dan benchmarking visual terhadap referensi antarmuka kelas dunia.
- **`image-to-ui`**: Rekonstruksi gambar atau wireframe menjadi komponen antarmuka yang presisi dan interaktif.

### 22. Vision & Multimodal Understanding Skills
*(Native Antigravity Skills di `.agents/skills/vision/`, `.agents/skills/vision-multimodal/`, dan `.agents/skills/qianwen-vision/`)*
Digunakan untuk analisis gambar, dokumen/PDF, denah tata ruang, tangkapan layar antarmuka SLiMS, OCR teks, dan penalaran multimodal:
- **`vision`** (`.agents/skills/vision/SKILL.md`): Delegasi pemahaman visual (OpenAI-compatible) via script `see.py` untuk inspeksi gambar, diagram sistem, dan tangkapan layar.
- **`vision-multimodal`** (`.agents/skills/vision-multimodal/SKILL.md`): Analisis dokumen/PDF, perbandingan multi-gambar, ekstraksi tabel/teks, dan interpretasi visual berbasis Claude multimodal.
- **`qianwen-vision`** (`.agents/skills/qianwen-vision/SKILL.md`): Pemahaman visual mendalam dan ekstraksi teks berpresisi tinggi berbasis model Qwen VL / QVQ (`analyze.py`, `reason.py`, `ocr.py`) untuk analisis visual, video, dan penalaran bertahap (chain-of-thought).

### 23. Collaborative Brainstorming & Dynamic Co-Creation Skill
*(Native Antigravity Skill di `.agents/skills/collaborative-brainstorming/SKILL.md`)*
Digunakan untuk:
- Mengubah interaksi agent menjadi mitra berpikir setara (*intellectual sparring partner*) yang aktif, hangat, dan sangat terbuka terhadap masukan pengguna (*radical receptivity*).
- Menjalankan protokol 5 tahap penerimaan masukan (*Active Ingestion -> Yes-and Expansion -> Reality Calibration -> Multi-Option Menu -> Joint Decision*).
- Memfasilitasi sesi brainstorming menggunakan metode SCAMPER, 6 Thinking Hats De Bono, Socratic Questioning, dan Reverse Brainstorming.
- Menghadirkan menu alternatif spektrum (Konservatif, Hybrid Cerdas Rekomendasi, Roadmap Dekanat) saat mengevaluasi ide baru pengguna.
