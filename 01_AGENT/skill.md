# Daftar Skill AI Agent (PMSI Perpustakaan FT UNY)

Berikut adalah keahlian (*skills*) yang dapat digunakan oleh AI Agent dalam project ini, baik yang bawaan repositori maupun *Native Antigravity Skills* di folder `.agents/skills/`:

---

### 1. Academic Skill
*(Native Antigravity Skill di `.agents/skills/academic-skill/SKILL.md`)*
Digunakan untuk penulisan laporan akademik.
Ketentuan:
- Bahasa Indonesia akademik natural, merujuk pada 7 Aspek MSI Bu Ratna.
- Tidak kaku; anti-AI Writing (tanpa kata *slop* dan tanpa tanda *em-dash*).
- Mempertahankan solusi *Pure Governance* (tanpa memaksakan koding software baru).
- Menegakkan *Vertical Alignment 3 Tingkat Organisasi* (Dekanat, Pustakawan Tunggal, Pemustaka).

---

### 2. Source Tracking / Revisi Skill
*(Native Antigravity Skill di `.agents/skills/revisi/SKILL.md`)*
Digunakan untuk:
- Melacak sumber dan tidak membabat habis paragraf lama saat revisi (*Substance First*).
- Menjaga garis keturunan artefak (*lineage*) antar-modul.
- Membuat histori revisi di folder `07_REVISI/`.

---

### 3. Self Audit Skill (QA/QC)
*(Native Antigravity Skill di `.agents/skills/self-audit/SKILL.md`)*
Digunakan untuk:
- Memeriksa laporan dan mewajibkan standar Diagram `mermaid`.
- Protokol *Push-Back*: Menolak instruksi yang menyalahi pakem MSI atau menebak angka fiktif.
- Memeriksa kelengkapan 7 Bagian wajib Laporan Praktikum.

---

### 4. Modul Generator Skill
*(Native Antigravity Skill di `.agents/skills/buat-modul/SKILL.md`)*
Digunakan untuk:
- Memandu tata cara pembuatan Laporan Modul baru secara konsisten.
- Mewajibkan *Implementation Plan* sebelum menulis kode/naskah utuh.

---

### 5. Obsidian Graph Skill
*(Native Antigravity Skill di `.agents/skills/obsidian-graph/SKILL.md`)*
Digunakan untuk:
- Manajemen graf pengetahuan Obsidian dan resolusi simpul terisolasi (*orphan nodes*).
- Menjaga Dashboard sebagai *Mother Hub / Central Nexus* (Jantung Utama Graf).
- Menerapkan standar *bidirectional wikilinking* lintas folder.

---

### 6. Self-Healing Skill
*(Native Antigravity Skill di `.agents/skills/self-healing/SKILL.md`)*
Digunakan untuk pemulihan dan perbaikan mandiri:
- Deteksi dan perbaikan otomatis tautan rusak (*broken wikilinks*) ke file target riil.
- Perbaikan otomatis sintaks diagram Mermaid yang gagal render.
- Rekonsiliasi diskontinuitas deliverable (mengembalikan deliverable yang hilang di modul lanjutan).
- Koreksi akuntabilitas RACI (1 Accountable tunggal) dan eliminasi em-dash / AI slop words.

---

### 7. Problem Solving & Systemic Reasoning Skill
*(Native Antigravity Skill di `.agents/skills/problem-solving/SKILL.md`)*
Digunakan untuk:
- Menelusuri akar masalah menggunakan metode *5-Whys* dan *Diagram Ishikawa (Fishbone)*.
- Menganalisis keputusan dengan *Trade-Off Matrix* (membuktikan keunggulan tata kelola dibanding koding aplikasi baru).
- Memastikan kategorisasi kendala dan solusi bersifat *MECE (Mutually Exclusive, Collectively Exhaustive)*.

---

### 8. Fact-Checker & Evidence Verification Skill
*(Native Antigravity Skill di `.agents/skills/fact-checker/SKILL.md`)*
Digunakan untuk:
- Audit triangulasi bukti 3 pilar: Transkrip Wawancara, Catatan Kuliah Bu Ratna, dan Modul.
- Mencegah halusinasi data (blacklist klaim fiktif seperti penambahan staf magang atau sistem custom pusat).
- Mengklasifikasikan status informasi: `[FACT: Wawancara 3]`, `[DOCTRINE: Bu Ratna]`, `[ASSUMPTION: Terkendali]`.

---

### 9. Enterprise Architecture Skill
*(Native Antigravity Skill di `.agents/skills/enterprise-architecture/SKILL.md`)*
Digunakan untuk:
- Pemodelan arsitektur sistem enterprise 4-Layer baku (*Business, Data, Application, Technology Layer*).
- Pemetaan alur data sirkulasi SLiMS 9 Bulian menuju Borang Akreditasi LAM-INFOKOM Kriteria 5.
- Penyelarasan sistemik antara pemustaka, pustakawan tunggal, dan Dekanat FT UNY.

---

### 10. Change Management Skill
*(Native Antigravity Skill di `.agents/skills/change-management/SKILL.md`)*
Digunakan untuk:
- Menganalisis potensi resistensi pemangku kepentingan berbasis *Power-Interest Grid*.
- Merancang transisi budaya kerja pustakawan dan pemustaka menggunakan model *ADKAR*.
- Menegakkan pembagian peran tata kelola transisi dengan prinsip *RACI Governance*.

---

### 11. Defense-Prep Skill
*(Native Antigravity Skill di `.agents/skills/defense-prep/SKILL.md`)*
Digunakan untuk:
- Menyiapkan tangkisan argumen resmi (*counter-arguments*) terhadap pertanyaan kritis dosen (Bu Ratna).
- Pembagian peran suara saat presentasi kelompok (Gantar: SOP & Tata Kelola; Ganendra: Form & Pemustaka; Fadlan: SLiMS & Borang).
- Mode simulasi interaktif responsi (*Grilling / Devil's Advocate Mode*).

---

### 12. Executive-Synthesis Skill
*(Native Antigravity Skill di `.agents/skills/executive-synthesis/SKILL.md`)*
Digunakan untuk:
- Menyusun *Executive Summary 1-Halaman* untuk pimpinan fakultas (Dekanat FT UNY).
- Mengonsolidasikan rantai nilai deliverable Modul 1 s.d. 7 ke dalam bundel portofolio akhir yang kohesif.
- Menghubungkan seluruh ringkasan eksekutif ke *Master Hub* `[[Dashboard]]`.

---

### 13. Information Routing Skill
*(Native Antigravity Skill di `.agents/skills/information-routing/SKILL.md`)*
Digunakan untuk:
- Mencegah "salah kamar" penempatan file (`02_LAPORAN/` vs `07_REVISI/` vs `08_ARTEFAK/`).
- Menempatkan narasi pada struktur 7 bagian baku secara presisi (fakta di Bag 3, hasil di Bag 4, kendala di Bag 5).
- Menjaga kepatuhan konvensi penamaan (`Praktikum_X_Kelompok3.md`, `SOP-001`, `FORM-001`).

---

### 14. Source Retrieval Skill
*(Native Antigravity Skill di `.agents/skills/source-retrieval/SKILL.md`)*
Digunakan untuk:
- Investigasi 3 titik wajib (Modul Praktikum, Catatan Kuliah Bu Ratna, Transkrip Wawancara).
- Pemindaian radar indeks repositori (`SOURCE_INVENTORY.md` dan `KNOWLEDGE_GRAPH.md`).
- Menghilangkan *blindspot* dan menjamin garis keturunan deliverable modul lampau.

---

### 15. Systemic Reasoning Skill
*(Native Antigravity Skill di `.agents/skills/systemic-reasoning/SKILL.md`)*
Digunakan untuk:
- Penalaran hukum dasar (*First-Principles Thinking*) membedah kendala fisik pustakawan tunggal.
- Pemodelan ikatan sebab-akibat (*Causal Loop Diagram*) dan intervensi pemutus masalah.
- Uji dialektika (Tesis - Antitesis - Sintesis) untuk mematangkan rekomendasi manajerial.

---

### 16. Prose Crafting Skill
*(Native Antigravity Skill di `.agents/skills/prose-crafting/SKILL.md`)*
Digunakan untuk:
- Mengatur variasi ritme dan kedalaman kalimat (*burstiness & flow*).
- Menerapkan diksi manajerial resmi Indonesia (disparitas, distorsi, cognitive load, rekonsiliasi).

### 17. System Blueprint Skill
*(Native Antigravity Skill di `.agents/skills/system-blueprint/SKILL.md`)*

### 18. Visualization Skill
*(Native Antigravity Skill di `.agents/skills/visualization/SKILL.md`)*

### 19. Mockup Design Skill
*(Native Antigravity Skill di `.agents/skills/mockup-design/SKILL.md`)*

- Menjalankan simulasi data interaktif lintas peran (Live Queue, Timer Quiet Hour, 1-Click LAM-INFOKOM Converter).
