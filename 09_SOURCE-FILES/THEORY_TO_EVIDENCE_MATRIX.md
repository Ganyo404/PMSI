# Theory to Evidence Matrix (MSI)

Matriks ini memetakan teori dari Dosen (Modul Pembelajaran) terhadap implementasi di lapangan (Laporan Praktikum & Temuan Wawancara). Matriks ini berfungsi agar Agent selalu dapat melandasi argumen analisis proyek dengan referensi akademik yang diajarkan di kelas.

| Modul Pembelajaran | Konsep Teori Utama | Bukti Lapangan / Artefak Proyek | Status Keterkaitan |
| :--- | :--- | :--- | :--- |
| **[[Modul 1.md\|Modul 1]]** | Konsep Dasar SIM, Nilai Bisnis Sistem Informasi, dan Klasifikasi Sistem. | Pemilihan SLiMS Perpustakaan FT UNY sebagai sistem transaksional (TPS) yang belum termanfaatkan optimal secara manajerial (`[[LAP-001]]`, `[[WAW-002]]`). | Tervalidasi |
| **[[Modul 2.md\|Modul 2]]** | Analisis Stakeholder, *Vertical Alignment*, & Lingkungan Bisnis. | Identifikasi Pustakawan sebagai Operator, Dekanat sebagai level Strategis, dan LAM-INFOKOM sebagai Faktor Eksternal (`[[LAP-002]]`, `[[FIND-011]]`). | Tervalidasi |
| **[[Modul 3.md\|Modul 3]]** | Analisis Masalah (Root Cause), Efisiensi Proses Bisnis. | Masalah beban ganda (multi-tasking) Pustakawan yang menyebabkan *delay* pemutakhiran data sirkulasi (`[[LAP-003]]`, `[[WAW-001]]`, `[[FIND-010]]`). | Tervalidasi |
| **[[Modul 4.md\|Modul 4-6]]** | Desain Tata Kelola (IT Governance), *Scope Management*, dan SOP. | Keputusan berani untuk membatasi *scope* (*Out-of-Scope*) dan menggunakan *Pure Governance* (SOP *Quiet Hour*, Rak Transit) daripada membuat aplikasi koding baru (`[[LAP-004]]`, `[[FIND-001]]`, `[[FIND-009]]`). | Tervalidasi |
